Week 2: Dynamic web Application & database

A Flask application with an SQLite visit counter.

Status: Completed

This project uses a Python Flask backend and an SQLite database to track page visits.

Visit counter

Database & storage

The visit count is stored in the stats table in the SQLite database file counter.db. Each page visit increments the count, and the database file preserves it when the server restarts.

Restart test

The screenshots show the counter before a server reboot and after the server restarted. The count was still present after the reboot; it increased from 153 to 155 as additional visits were recorded.
