Week 1: First Linux Web Server

Linux virtual machine and web server project on CSC cPouta.

Status: Completed

In this week's project i created Linux virtual machine in CSC cPouta. Configured security groups and installed Nginx to serve static HTML pages.

1. Linux distribution and version

Ubuntu 26.04 LTS

2. What is Nginx?

Nginx is light web server what handles incoming HTTP requests and delivers web pages to users.

3. Commands used

1. Refresh the local package index with latest uptades.

sudo apt update

2. Download and install the nginx web server.

sudo apt install -y nginx

3. Enable nginx to start automatically on system boot.

sudo systemctl enable nginx

4. Check current running status and healt of nginx service.

sudo systemctl status nginx
